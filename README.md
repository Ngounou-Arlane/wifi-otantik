# Wifi-Otantik

SaaS hotspot + PPPoE multi-tenant plugin for PHPNuxBill.

## Features

- Multi-tenant WiFi zone management
- MikroTik router integration
- Customer/subscriber management
- Plans and pricing
- Reseller system
- ERP with income/expense tracking
- WhatsApp integration
- Payment gateways
- Ticketing system
- Map visualization
- Monitoring and supervision

## Installation

1. Copy the plugin files to your PHPNuxBill installation:
   - `wifi_otantik.php` → `system/plugin/`
   - `autoload/` → `system/autoload/`
   - `ui/` → `system/plugin/ui/`

2. Configure the plugin through the PHPNuxBill admin panel

## Requirements

- PHPNuxBill
- PHP 7.4+
- MySQL/MariaDB
- MikroTik RouterOS (for hotspot functionality)
